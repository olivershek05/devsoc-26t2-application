# # devsoc-26t2-application

## https://olivershek05.github.io/devsoc-26t2-application/index.html

This is the first website I've ever made and took about a week to complete! Initially I barely knew HTML and CSS, and forgot most of the JavaScript I learned from COMP1531, but have learned a lot of concepts while making this website.  

To address the day/night theme, I created my website using two pages - an 'About Me' and an 'Interests' page. As it is typical to work during the daytime (office hours), I decided to make the 'About Me' page a professional snapshot of myself whilst using a daytime themed navigation bar and background. In contrast, the 'Interests' page has a nighttime themed navigation bar and background, and highlights other aspects of myself outside of my professional/academic background, representing the freedom that comes after finishing work for the day.
